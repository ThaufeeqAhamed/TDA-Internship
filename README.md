# Week 4: Sales Data Visualization Project

## 📊 Project Overview
This project is a complete data analysis and visualization pipeline built with Python. It automates the process of loading raw sales data, cleaning it, and generating professional business charts (Bar, Pie, and Line charts) to reveal key insights.

**Objective:** To demonstrate the ability to programmatically visualize trends and distributions using the `matplotlib` and `pandas` libraries.

## 🛠️ Tech Stack
- **Python 3.x**
- **Pandas** (Data Manipulation)
- **Matplotlib** (Data Visualization)
